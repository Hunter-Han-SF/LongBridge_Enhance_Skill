# 2026-11-10 theta 死字段修复记录（0.6.1）

修复基准：`0e2eb47`（main，0.6.0）。分支：`fix/theta-dead-field-20261110`。

## 问题

`get_option_quote.py` 输出的 theta 恒为 `0.0000 /日`，且来源标注"服务端原生
Greeks(calc-index)"——看起来是真实数据，实际是 Longbridge calc-index 端点返回的
死值。该问题在 2026-11-03 审计期间已被口头识别，但未落入 27 项修复清单，因此
v0.6.0 未修、审计文档零记录（本文件补上这段书面痕迹）。

## 根因（六层因果链）

| 层 | 失守点 |
|---|---|
| 1. 服务端 | calc-index 返回格式化的 -0.000 而非 null/报错——"长得像数据的垃圾"，不会触发下游任何防御 |
| 2. 入口实测 | 2026-08 字段实测（`common.py:1359` 注释）只验证了字段**存在**，未验证值**有效**；同批 delta/vega 正确背书了假字段的合法性 |
| 3. 透传层 | `to_float(m.get("theta")) or 0.0` 把"上游没给"和"上游给了 0"折叠成同一输出；0 又在 theta 合法值域内（临近到期深度价内 ≈0 合法），无法区分 |
| 4. 回退层 | BS 回退条件 `if not greeks`（整体失败才触发）为"端点瘫痪"设计，不防"端点部分掺假"——服务端返回有效 delta，回退永远轮不到 |
| 5. 审计层 | 11-03 审计为离线数学/逻辑审计（"未调用证券账户或真实行情"），"服务端送来垃圾"在其方法论下不可见；theta 口头识别但未落清单，清单是修复唯一源头，不在清单 = 不存在 |
| 6. 文档层 | SKILL.md 的 `theta=/日` 宣传行从未被重验；v0.6.0 的文档"同步"是传播既有声明而非重验 |

## 修复设计

### theta 单独溯源（`theta_source` 字段）

| theta_source | 含义 | 触发条件 |
|---|---|---|
| `server` | 服务端可信非零值 | 原生路径且 theta ≠ 0 |
| `bs_backfill` | 服务端死值 → 本地 BS 补算 | 原生路径、theta == 0、T > 0、IV > 0 |
| `black_scholes` | 原生整体失败 → 全套 BS | 原有回退路径不变 |
| `dead_zero` | 服务端死值且无法补算，不得当真实数据用 | theta == 0 且（无 IV / 已到期 / BS 拒算） |

文本输出同步标注：`theta = -0.2011 /日  ⚠️BS补算(服务端死值)` 或
`theta = 0.0000 /日  ⚠️服务端死值,无有效数据`。

### 补算边界（对应审计 11 项确立的 BS 边界行为）

- 已到期（T ≤ 0）不补算：BS 在到期折点退化/拒算，theta 0 本就是退化正确值，
  由既有的到期 warning 覆盖
- `bs_greeks` 抛 ValueError（到期折点等）→ 降级 `dead_zero`，不中断原生路径
- 服务端 theta 若日后修复为非零值，自动直接采信（`server`），无需改代码

### 数据层契约不变

`get_option_contract_metrics` 保持忠实透传（不修补），死值警告写入模块注释与
docstring；补算决策留在消费层（`get_option_quote`），Wall/GEX/MaxPain 等
gamma/oi 消费方不受影响（它们不请求 theta）。

## 附加修复：chain 同 strike 重复行

实测（2026-11-10 美股收盘后）暴露：`get_option_chain` 对同一行权价可返回
重复行——"零值行 + 真实行"并存：

```
{'strike': 185, 'put_last': 0,  'put_iv': 0.0,  'put_vol': 0,    ...}
{'strike': 185, 'put_last': 14.0, 'put_iv': 0.574, 'put_vol': 1323, ...}
```

原查找逻辑"首个匹配即 break"可能被零值行抢占 → IV/价格全丢 → theta 补算
无原料（本次实测第一遍即命中）。修复：首个匹配仅作兜底，继续等一行本侧
IV 有效的真实数据；整链只有零值行时如实保留（不伪造）。

## 接口和兼容性变化

1. `get_option_quote` JSON 输出新增 `theta_source` 字段（纯新增，向后兼容）；
   文本输出的 theta 行在补算/死值时带 `⚠️` 标注。
2. `calc_option_greeks` 组合层逐腿调用 `get_quote`，补算后的 theta 自动传导
   至加权合计（含 ×100 合约乘数），无需改动。
3. 无破坏性变更：原生 Greeks 可用时 delta/gamma/vega/rho 输出与 0.6.0 一致。
